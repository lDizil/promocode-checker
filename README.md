# PromoCode Checker

Учебный сервис для поиска и проверки промокодов.

## Идея

Пользователь выбирает поддерживаемый сервис, находит промокод или вводит свой для проверки. Backend сам подбирает товары и собирает внутреннюю тестовую корзину, применяет код и показывает фактический результат с условиями. Пользователь корзину у нас не собирает и её параметры не заполняет.

## MVP

- выбор одного поддерживаемого сервиса;
- поиск промокодов по выбранному сервису;
- ручная проверка своего промокода;
- автоматическая сборка тестовой корзины внутри backend без участия пользователя;
- результат проверки: статус, скидка, ограничения и время проверки;
- проверка на контролируемых тестовых аккаунтах без пользовательских паролей, cookies и сессий.

Нейросеть можно использовать для разбора и объяснения условий промокода. Финальный статус «работает» подтверждается фактической проверкой корзины.

Нужна ли регистрация и какие способы входа поддерживать — открытый продуктовый вопрос. Проверка не должна архитектурно зависеть от наличия аккаунта пользователя.

## Структура

```text
frontend/  — клиентское приложение
backend/   — API, каталог промокодов и проверка кодов
docs/      — продуктовые и архитектурные материалы
```

Технологический стек будет выбран после первичного архитектурного исследования.
