# zod-схемы во фронтенде — контракт API, пока у бэкенда нет OpenAPI

Бэкенд ещё не готов, а фронтенду нужны типы, моки и валидация ответов уже сейчас. Контрактом служат zod-схемы DTO в `modules/*/api`; из них же выводятся TypeScript-типы, фабрики фейковых данных и ответы MSW. Ответ сервера парсится строго (`parse`) во всех окружениях: несовпадение бросает `ApiContractError` и показывает `ErrorState`, потому что показ оффера с искажёнными условиями противоречит ARD ADR-01.

## Considered Options

- OpenAPI-спека первой с генерацией zod, клиентов и MSW (orval/kubb): требует, чтобы бэкенд принял спеку до начала работы.
- `safeParse` в проде с частичным рендером: скрывает расхождения контракта от пользователя ценой неверных условий.

## Consequences

Когда у бэкенда появится OpenAPI, схемы в `api/` заменяются сгенерированными; `model/`, `hooks/` и `ui/` модулей при этом не меняются.
