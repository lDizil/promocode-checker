# UI kit в `common/ui` с исключением из правил FEOD

FEOD требует, чтобы `common` состоял из однофайловых сущностей без `index.*` и глубже одного уровня. Компоненты UI kit многофайловые (`.tsx`, `.module.css`, `.stories.tsx`), поэтому по FEOD им место в модуле `modules/ui-kit`. Команда выбрала `common/ui`: kit — это нижний слой без бизнес-логики, и импорт `@/common/ui/Button/index.ts` читается как «общий примитив». FEOD не умеет ослаблять правила для одной папки (`no-common-index` срабатывает и на стороне импортирующего файла), поэтому в oxlint `no-common-index` выключен целиком, а `common.maxDepth` поднят до 2. Вне `common/ui` барели в `common` по-прежнему не заводим — это проверяется ревью.

## Consequences

- В `common/ui` лежат только примитивы без доменных типов. Доменные композиты (`OfferCard`, `CodeBox`, `ScoreBadge`, `MerchantTile` и т. п.) живут в `modules/*/ui`: `common` не может импортировать модули.
- Импорт `@ui-sdk/*` и `lucide-react` разрешён только в `common/ui`, чтобы смена или обновление ui-sdk (beta) затрагивали один слой.
- `useEffect` в `common/ui` запрещён линтером: компоненты чисто презентационные.
